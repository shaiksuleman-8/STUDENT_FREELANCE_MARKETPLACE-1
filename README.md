\# 🎓 Student Freelance Marketplace



A web-based platform that connects students with freelance opportunities, allowing students to showcase their skills, find projects, and earn money through their talents.



\## 🚀 Features



\- Student Registration and Login

\- User Authentication

\- Student Profile Management

\- Browse Freelance Projects

\- Post Freelance Jobs

\- Apply for Projects

\- Manage Freelance Applications

\- Responsive User Interface



\## 🛠️ Technologies Used



\- \*\*Frontend:\*\* HTML, CSS, JavaScript, Bootstrap

\- \*\*Backend:\*\* Python, Django

\- \*\*Database:\*\* MySQL

\- \*\*Development Tools:\*\* VS Code, Antigravity, Git, GitHub



\## 💻 Installation and Setup



\### 1. Clone the Repository



```bash

git clone https://github.com/shaiksuleman-8/STUDENT\_FREELANCE\_MARKETPLACE-1.git

```



\### 2. Navigate to the Project



```bash

cd STUDENT\_FREELANCE\_MARKETPLACE-1

```



\### 3. Create a Virtual Environment



```bash

python -m venv venv

```



\### 4. Activate Virtual Environment



Windows PowerShell:



```powershell

.\\venv\\Scripts\\Activate.ps1

```



\### 5. Install Dependencies



```bash

pip install -r requirements.txt

```



\### 6. Configure Database



Configure your MySQL database credentials in your Django settings or environment variables.



\### 7. Run Migrations



```bash

python manage.py migrate

```



\### 8. Start the Development Server



```bash

python manage.py runserver

```



Open your browser:



http://127.0.0.1:8000/

The main objective of this project is to help students discover freelance opportunities, improve their professional skills, gain practical experience, and earn income.
